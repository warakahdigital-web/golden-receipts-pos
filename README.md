# POS Reborn

أريد منك استرداد وبناء النظام بناءً على النسخة الأولى الاحترافية المنشورة على هذا الرابط:

https://sahab-erp-system-dev-9461.bolt.host



المطلوب بدقة:

1. استعادة كود وتصميم واجهة نقطة البيع (POS) بنفس الألوان والشعار والتنسيق العربي الـ RTL الظاهر في الرابط أعلاه دون أي تغيير في الشكل.

2. عدم تغيير أو حذف أي شاشة كانت تعمل سابقاً (شاشة الكاشير والمنتجات).

3. فقط أضف فوق هذه الواجهة شاشة تسجيل دخول (Login Page) بسيطة وأنيقة بنفس ألوان الهوية البصرية (الكحلي والذهبي).

4. بعد إضافة شاشة الدخول، توقف وانتظر ملاحظاتي للتأكد من أن التصميم عاد كاملاً كما كان في

 الأول.
